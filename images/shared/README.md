# Shared images (MJ)

Images used on every page: logo, favicon, shared icons. MJ manages this folder.
For a single page, use that page's own folder instead.

Link them from an HTML file like this:

    <img src="images/shared/logo.png" alt="[Website Name] logo">

Naming: lowercase, hyphens instead of spaces, no Korean, keep the extension
lowercase (`.png`, not `.PNG`). Compress large photos before uploading.
